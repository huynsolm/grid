# U2 문서·설정 검증

검증일: 2026-10-21

U1 완료 후 승인 계획의 U2를 구현했다. 설계 개정 5의 수치·기능 범위와 인쇄 CSS는 변경하지 않았다.

- 문서 모델 version 1, 시스템 기본 폰트 레코드, 색/범위/유한수/중복 ID/글꼴 참조 검증을 추가했다.
- 상태 저장소는 입력과 분리된 읽기 전용 스냅샷을 반환한다. 모든 변경은 명령 적용 → 전체 검증 → 상태 반영 → 구독자 통지 순서로 진행한다. 잘못된 명령은 상태와 통지를 바꾸지 않는다.
- 초기화/복원은 편집과 구분하고 이력 대상에서 제외한다. 명령은 변경 전후 값과 그룹 식별자를 전달한다. 최근 100개 이력 정책은 U5 작업으로 남긴다.
- 이후 U3가 사용할 글상자 추가/수정/삭제 명령도 같은 경로에 마련했다. 방향/여백 변경은 기존 글상자의 좌표·폭·서식을 바꾸지 않는다.
- 기본 화면 `/`에는 A4 방향, 사방 여백 0~20mm 정수, 모눈 간격 1/2/5/10mm, 선 색·불투명도·굵기, 없음/5칸/10칸 강조선, 격자 스냅을 연결했다. 상태는 아직 메모리에서만 유지된다.
- 강조선은 기본선과 중복하지 않고 굵기는 2배다. 부분 칸과 1mm 모눈의 불투명도 권장 안내를 표시하며 설정을 강제 변경하지 않는다.
- 검증용 글자·붉은 기준선은 `/?validation=1`에서 유지한다. 기본 모눈에는 포함하지 않는다. 기존 U1 파일은 보존했다.

## 확인 결과

- 단위 검사 **34개 통과**: 문서 경계, 불변성, 명령/통지, 초기화/복원 구분, 텍스트 좌표 보존, mm 변환·확대 역변환, 간격·강조선·부분 칸.
- 브라우저 검사 **24개 통과**: Chromium/Chrome/Edge 각각 기존 U1 6개 + U2 설정 2개. 잘못된 여백 입력의 상태 보존, 실제 SVG 속성 변경, 인쇄 매체의 UI/확대 제거를 확인했다.
- TypeScript 검사 및 배포 빌드 통과.
- 기본·10mm 강조선 설정·인쇄 매체 화면을 직접 확인했다. `docs/qa/tmp/u2-default-screen.png`, `u2-configured-screen.png`, `u2-configured-print-media.png`에 로컬 증거를 남겼다.
- U1 기존 `u1-print-media.png`와 같은 Chromium/뷰포트에서 새 검증 경로를 캡처한 `u2-u1-regression-chromium.png`는 크기와 픽셀이 일치했다. Chrome 캡처는 브라우저 래스터 차이가 있어 별도로 보관했다. 이 화면 비교는 새 설정 전체의 실제 인쇄 대화상자 검증을 대체하지 않으며 전체 수용 PDF 검사는 U6에서 수행한다.

U2 검증을 통과했다. 후속 글쓰기/IME는 U3, 저장·복원은 U4, 이력 정책과 전체 출력 준비는 U5에서 연결한다.
